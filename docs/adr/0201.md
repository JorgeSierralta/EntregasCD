# Ejercicios — Tema 2: Ingeniería de Software

## Ejercicio 1 — Diseño con Tarjetas CRC

##### Sistema de gestión de una biblioteca que permite registrar libros y socios, gestionar préstamos y devoluciones.

### 1. Tarjeta CRC

#### Tarjeta CRC: Libro

| **Clase: Libro**                            |                   |
| ------------------------------------------- | ----------------- |
| **Responsabilidades**                       | **Colaboradores** |
| Conocer su título, autor e ISBN             | -                 |
| Conocer el número de ejemplares disponibles | -                 |
| Prestar un ejemplar (si hay disponibles)    | Préstamo          |
| Recibir la devolución de un ejemplar        | Préstamo          |

#### Tarjeta CRC: Socio

| **Clase: Socio**                                      |                   |
| ----------------------------------------------------- | ----------------- |
| **Responsabilidades**                                 | **Colaboradores** |
| Conocer su nombre, numero de afiliado y fecha de alta | -                 |
| Solicitar préstamos de libros                         | Libro, Préstamo   |
| Devolver libros prestados                             | Préstamo          |

#### Tarjeta CRC: Préstamo

| **Clase: Préstamo**                          |                   |
| -------------------------------------------- | ----------------- |
| **Responsabilidades**                        | **Colaboradores** |
| Conocer qué libros y socios están implicados | Libro, Socio      |
| Conocer fecha de inicio del préstamo         | -                 |
| Registrar la devolucion de un préstamo       | Libro             |

### 2. Relación entre las clases

- **Socio** (nombre, numeroAfiliado, fechaAlta) &rarr; solicita &rarr; **Préstamo** (fechaInicio, fechaDevolucion) &rarr; sobre &rarr; **Libro** (titulo, autor, ISBN, disponibilidad)

1. Se comprueba si **Libro** tiene ejemplares disponibles (>0).
2. Si los hay: se descuenta un ejemplar de la lista de disponibles y se crea un **Préstamo** que vincula **Libro** con **Socio**. la operacion se considera exitosa.

3) Si no los hay: no se crea **Préstamo** y no se modifica la lista de disponibles. La operacion se considera fallida.
4) Al devolver un ejemplar el **Préstamo** se marca como finalizado y **Libro** añade 1 a la lista de disponibles.

### 3. Descripción del flujo

| Paso | Acción                            | ¿Éxito? | Ejemplares disponibles tras la acción |
| ---- | --------------------------------- | ------- | :-----------------------------------: |
| 1    | Alta del libro                    | Sí      |                   3                   |
| 2    | Alta del socio A                  | Sí      |                   3                   |
| 3    | Alta del socio B                  | Sí      |                   3                   |
| 4    | Socio A toma prestado un ejemplar | Sí      |                   2                   |
| 5    | Socio B toma prestado un ejemplar | Sí      |                   1                   |
| 6    | Socio A devuelve un ejemplar      | Sí      |                   2                   |
| 7    | Socio B toma prestado un ejemplar | Sí      |                   1                   |

Nota: Si cuando un socio toma un libro añadimos la restriccion de no poder tomar otro hasta hacer la devolución del actual podriamos decir que:

| Paso | Acción                            | ¿Éxito? | Ejemplares disponibles tras la acción | Pases socio A | Pases socio B |
| ---- | --------------------------------- | ------- | :-----------------------------------: | :-----------: | :-----------: |
| 1    | Alta del libro                    | Sí      |                   3                   |       -       |       -       |
| 2    | Alta del socio A                  | Sí      |                   3                   |       1       |       -       |
| 3    | Alta del socio B                  | Sí      |                   3                   |       1       |       1       |

| 6    | Socio A devuelve un ejemplar      | Sí      |                   2                   |       1       |       0       |
